# Bài thực hành 6 - Vue.js

Ba bài tập được tách thành các trang độc lập:

- `bai_1/`: Thẻ thông tin sinh viên (`index.html`, `app.js`, `style.css`, `student-avatar.svg`).
- `bai_2/`: Đặt vé xem phim (`index.html`, `app.js`, `style.css`).
- `bai_3/`: Quản lý công việc cá nhân (`index.html`, `app.js`, `style.css`).

Mở trực tiếp `index.html`, hoặc truy cập `http://localhost/Bui-Xuan-Chung_23001838/thuc_hanh_6/` sau khi bật Apache trong XAMPP. Trang mục lục dẫn đến từng bài. Không cần MySQL, cài đặt npm hay bước build.

Vue 3 đã được đặt trong `lib/vue.global.prod.js`, vì vậy các bài chạy ngay cả khi không có mạng. Giấy phép MIT của Vue nằm trong `lib/LICENSE.vue.txt`. Mỗi bài có mã HTML, JavaScript và CSS trong thư mục riêng để dễ xem và sửa.
